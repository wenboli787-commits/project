# 三种动作重定向方法主要比较结果

## 技术摘要

- 本次严格配对比较 9 个动作：05_04, 111_23, 113_20, 113_21, 114_15, 124_11, 135_04, 47_01, 76_10；每个动作在方法平均中权重相同。
- Basic IK 的相对 MPJPE 和末端误差最低，但审计后的关节超限帧率仍为 100%，不能仅凭姿态误差判定其最好。
- GMR 的关节限制和 MuJoCo 自碰撞代理最好，但穿地超过 5 mm 的帧率最高。
- Direct Mapping 的根轨迹误差、穿地帧率和平均关节 jerk 最低；Direct 的可见网格非父子重叠审计为 100.000%，更严格的非局部重叠为 27.360%。
- 不生成单一总分或“总冠军”，因为指标单位、可靠性和任务权重不同。

## 重要限制

1. 当前 MuJoCo 自碰撞率只覆盖 collision geoms，不能完整替代 visual mesh 穿模。
2. 当前逐动作足部滑动使用旧接触规则；主表中的“有效接触滑动”来自审计规则，但 GMR 的有效接触样本比例较低，必须与穿地率一起解读。
3. 当前 MPJPE 仍受关节映射和尺度定义影响，不是机器人关节角的绝对真值。
4. Basic IK 的一个测试仍引用旧文件名；正式动作发现器已经正确读取新的 `basic_ik_pure_unconstrained.pkl` 文件。
