# retarget_eval_toolkit

`retarget_eval_toolkit` 用原始人类动作作为 reference，评估机器人重定向后的 PKL 结果，并比较 Direct Mapping、Basic IK Retargeting、GMR 三种方法。

它会输出：

- `outputs/csv/quality_per_motion.csv`
- `outputs/csv/quality_per_method.csv`
- `outputs/csv/quality_aggregate.csv`
- `outputs/csv/frame_metrics_all.csv`
- `outputs/csv/missing_files.csv`
- `outputs/json/quality_raw_summary.json`
- `outputs/json/config_used.json`
- `outputs/figures/*.png`
- `outputs/report/RETARGETING_QUALITY_REPORT.md`
- `outputs/report/RETARGETING_QUALITY_REPORT.html`

## Install

Ubuntu 22.04 + Conda:

```bash
cd /mnt/d/GMR_WORK/retarget_eval_toolkit
conda create -n retarget_eval python=3.10 -y
conda activate retarget_eval
pip install -r requirements.txt
```

Optional features:

```bash
pip install mujoco
pip install smplx torch
```

`mujoco` is needed when PKL only has `root_pos/root_rot/dof_pos` and you want robot keypoints/joint limits from XML. `smplx torch` plus SMPL-X body model files are needed when AMASS/SMPL-X NPZ should be converted to full human keypoints.

## Run

```bash
cd /mnt/d/GMR_WORK/retarget_eval_toolkit
python eval_retargeting.py --config configs/eval_config.yaml
```

Or override paths:

```bash
python eval_retargeting.py \
  --original_root "/mnt/d/GMR_WORK/final use mode" \
  --direct_pkl_root "/mnt/d/GMR_WORK/GMR/outputs/direct_mapping_final/pkl" \
  --ik_pkl_root "/mnt/d/GMR_WORK/GMR/outputs/basic_ik_final/pkl" \
  --gmr_pkl_root "/mnt/d/GMR_WORK/GMR/outputs/final product/pkl" \
  --robot_xml "/mnt/d/GMR_WORK/GMR/assets/unitree_g1/g1_mocap_29dof.xml" \
  --output_dir "/mnt/d/GMR_WORK/retarget_eval_toolkit/outputs/final_eval"
```

## Important Notes

PKL loading uses Python `pickle`, which should only be used for trusted local files. The toolkit is intended for PKLs generated by your own GMR/Direct/Basic scripts.

The current `final use mode` NPZ files are AMASS/SMPL-style parameter files with keys like `poses`, `trans`, `mocap_framerate`, `betas`. Without SMPL-X model files, the toolkit can still use root trajectory from `trans`, but full human keypoint metrics are unavailable and reported as `NaN/not_available`.

The existing `GMR/outputs/final product/pkl` directory currently contains GMR final PKLs for several final actions. Direct Mapping and Basic IK final-action PKLs must be generated into matching directories before all three methods can be compared on the same motions.
